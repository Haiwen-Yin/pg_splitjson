# PG SplitJSON 0.2.0 支持矩阵

[English](support-matrix.md) | **简体中文** · [文档目录](README.zh-CN.md)

| 领域 | 已支持 / 已验证 | 边界 |
| --- | --- | --- |
| PostgreSQL | 18.6，已验证 PGXS 构建和独立回归 | 未声明支持其他大版本；跨大版本使用逻辑迁移 |
| 操作系统 / CPU | Linux x86_64、64 位，GCC 8.5 实验 | 其他平台需要自行构建和验证 |
| 物理 HA | 已验证崩溃恢复、WAL 归档 PITR、流复制回放和备库提升 | 要求相同 PostgreSQL minor/ABI 和扩展文件 |
| 逻辑备份 | 已验证整库 `pg_dump -Fc`/`pg_restore` | 只导出视图的 `pg_dump -t` 缺少内部存储依赖 |
| JSON 值 | 对象、数组、标量、JSON null；缺失与 JSON null 区分 | SQL NULL 文档/ID 拒绝 |
| 热路径 | 多级对象路径和固定非负数组下标，最多 64 条路径 × 每条 64 段 | 不支持重叠、通配或动态布局变化 |
| 更新 | 专用单字段、批量、删除和 numeric 增量 API；结构变化原生回退 | 普通文档 DML 重新拆分；不提供 JSONB 页内部分更新 |
| 查询 | 直接读取、等值辅助函数、JSONB/文本 B-tree 和已测精确 SELECT 改写 | 动态路径、不支持的转换/排序规则及任意查询形式保留原生计划 |
| 安全 | 视图安全屏障、角色授权和内部存储隔离 | 受管关系不支持 RLS |
| 关系 | 业务视图 + 内部普通 heap 表；类型化业务列 | 不支持分区受管关系和视图 `ON CONFLICT` |
| 复制 | 已验证物理复制和提升 | 不提供自动逻辑复制重组 |
| API 集成 | 明确的专用 API 契约 | 不提供完全 ORM 透明和通用 Oracle 风格 duality view |

所有性能数字都是特定负载的实测证据。生产批准前应在目标负载上验证延迟、WAL、锁等待、索引成本、vacuum 和膨胀。
